# 🐾 貓管家 (Cat Butler)

本專案為一個**單檔純前端、開箱即用**的貓咪照護整合工具，將「物資管理」、「寵物資訊」、「罐罐餵食日曆」與「貓食快篩」整合於單一 HTML 檔案中，離線即可完整運作。

> ⚠️ **聲明 Statement**：
> 本專案之所有程式碼（HTML / CSS / JavaScript）與介面邏輯，皆由 AI 協助生成與製作。

---

## ✨ 專案特點 (Highlights)

- **🧩 四大獨立模組整合**：頂部頁籤採獨立 `iframe` 架構與專屬主題色（紫／藍／橘／綠），切換流暢零閃爍，各模組保留獨立捲動狀態並透過訊息機制即時同步資料。
- **🔒 隱私安全與離線運作**：所有資料皆儲存於使用者本地瀏覽器（`localStorage`），不需註冊、不依賴後端伺服器，資料絕不上傳。
- **💾 整合式備份與分頁還原**：支援一鍵匯出四個模組的完整 `.json` 備份檔（附帶定期備份提醒燈號）；還原時提供**差異預覽視窗**，可比對筆數變化並自由勾選要覆蓋或保留的分頁。
- **💡 預設展示資料**：首次開啟網頁時顯示的範例內容純屬展示用途，非真實個人資料，可隨時清除或覆蓋。
- **🔗 適口性試算表連結**：支援自訂外部試算表網址，方便快速跳轉交叉比對毛孩的適口性與喜好紀錄。

## 📖 四大核心模組與操作說明 (Modules & How to Use)

### 1. 📦 物資管理 (Supplies)
- **物資卡與庫存總覽**：建立主食罐、餐包、乾糧、貓砂或保健品卡片，側邊欄即時統計罐頭／餐包總庫存。
- **雙消耗模式切換**：
  - **預估天數模式**：依現有庫存與每日消耗量，自動推算剩餘天數與補貨提醒。
  - **週期頻率模式**：適合固定頻率替換的物資（如貓砂、濾芯等）。
- **進階工具**：內建**歷史比價牆**、**隨機配餐**、滑鼠懸停觸發的**無縫跑馬燈**（顯示詳細週期與用量），以及**實體購買金額統計圖表**（支援深／淺色模式與琥珀色懸停高亮）。
- **跨模組連動**：可直接由物資項目跳轉至「貓食快篩」搜尋對應成分資料。

### 2. 🐾 寵物資訊 (Pet Profiles)
- **毛孩檔案與里程碑卡片**：記錄生日、品種、性別、絕育狀態、疫苗日期、晶片號碼與備註；自動換算精確年齡與出生天數，卡片支援寬螢幕自適應多欄佈局（最多 5～6 欄）與 2D 彈性旋轉星號互動。
- **🎂 獨家生日慶祝動畫系統**：自動偵測毛孩生日，當天卡片會觸發彩虹霓虹邊框光暈（Rainbow Glow Pulse）、光澤掃過（Shimmer Sweep）、10 色五彩紙屑飄落（Confetti Fall & Sway）與跳動蛋糕效果。

### 3. 📅 罐罐餵食日曆 (Feeding Calendar)
- 點擊日曆日期即可新增或檢視每日的罐罐與飲食紀錄、餵食時間點與備忘事項，並與物資管理資料即時連動。

### 4. 🔬 貓食快篩 (Cat Food Lab)
- **成分評分與多維篩選**：支援關鍵字搜尋、類型／產地篩選、分數排序與一鍵需求快篩（腎臟友善、幼貓、熟齡貓、高蛋白、低碳水、單一肉源、無膠、無誘食劑）。
- **飼料比較與庫存顯示**：支援多款飼料並排比較與完整評分標準檢視，列表自動對應顯示「物資管理」中的現有庫存數量。

## ⚙️ 資料備份與還原 (Backup & Restore)

- **完整備份**：點擊頂部「💾 完整備份」即可將四個分頁的資料打包下載為單一 `.json` 檔案。
- **選擇性還原**：點擊「📂 還原」選取備份檔後，系統會開啟**還原備份預覽視窗 (Restore Preview Modal)**，列出各分頁目前筆數與備份檔筆數的增減差異，勾選想要還原的分頁即可安全覆蓋，未勾選的分頁將完整保留。

## 🛠️ 技術棧 (Tech Stack)

- **Architecture**: Single-File Standalone HTML + Multi-iframe Hub (`postMessage` Cross-Frame Sync)
- **Core Framework**: [React 19](https://react.dev/)
- **Build / Runtime**: [Vite](https://vitejs.dev/) / ES Modules (`modulepreload`)
- **Storage**: Browser `localStorage` API (with cross-frame sync shim)
- **Styling & UI**: Native CSS3 Animations, Keyframes, CSS Grid / Flexbox, Backdrop Blur Toast, Modern Inline SVG
- **Theme Support**: Dark Mode / Light Mode & Per-Tab Dynamic Accent Themes
